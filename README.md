# Real Estate Investment Platform

Application Streamlit permettant la modélisation et l'analyse d'investissements immobiliers.

## Fonctionnalités

- Analyse des cash-flows immobiliers
- Calcul du TRI (IRR)
- Calcul de la VAN (NPV)
- Calcul du DSCR
- Calcul du Multiple Equity
- Analyse de sensibilité
- Modélisation du financement bancaire
- Valorisation à la sortie

## Installation

```bash
git clone https://github.com/fouadfouadbou99-boop/real_estate_appli.git
cd real_estate_appli
pip install -r requirements.txt
```

## Lancement de l'application

```bash
streamlit run app.py
```
